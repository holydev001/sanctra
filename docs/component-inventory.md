# Component Inventory

- `SiteNav`: sticky responsive public navigation; active-route styling; mobile disclosure; reusable across all public pages.
- `ThemeToggle`: persists the user’s dark/light choice; public now and dashboard reusable.
- `SanctraMark`: square S monogram with optional wordmark; globally reusable.
- `SiteFooter`: public architectural footer and oversized wordmark.
- `WaitlistForm`: role selection, email validation, and confirmation state; public-specific prototype behavior.
- `Section`: 1280px section shell with standard gutters, rhythm, border, and optional reveal.
- `SectionHeader`: eyebrow, fluid title, description, and left/center alignment.
- `Pill`: neutral, brand, success, warning, danger, and info status variants.
- `buttonClass`: primary, secondary, and ghost button recipes in medium/small sizes.
- `Card`: bordered surface with optional padding and interactive lift.
- `FeatureCard`: card specialization with icon, title, and explanatory copy.
- `TerminalWindow`: operational/code window with title and optional status.
- `CodeLine`: numbered diff/code row with add, remove, comment, and default tones.
- `Stat`: metric, label, and optional operational hint.

All primitives preserve keyboard focus, semantic elements, responsive composition, and square global geometry. Marketing routes compose these primitives without changing their visual contracts.
